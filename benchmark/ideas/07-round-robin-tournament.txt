I run small tabletop game tournaments with friends, and keeping track of everything on paper gets messy. I'd like one simple place where I can name the tournament, set the date, and add everyone who's playing. Before the tournament starts, I should be able to fix someone's name or remove them if they drop out. It shouldn't let me add the same person twice, and there should be at least three players before we begin.

Once everyone is added, I want the app to make the match schedule for me. Everyone should play everyone else once, and nobody should be put into two matches in the same round. Sometimes we'll have an odd number of players, so one person may need to sit out each round. After the schedule is made, the player list shouldn't be changeable by accident. If I really need to start the schedule over, I want a clear warning that the existing scores will be lost.

During the tournament, I want to enter the score for both players in each match. Draws are possible, and I sometimes make mistakes, so I need to be able to correct a score later. It would be helpful to quickly see which matches are finished and which are still waiting, and to narrow the list down by round or player. I also want to see how far through the tournament we are.

The standings should update by themselves whenever I add or change a score. A win is worth three points and a draw is worth one. For each player, I want to see how many matches they've played, won, drawn, and lost, along with points scored, points conceded, and their score difference. If players are tied, use score difference and then points scored to decide the order. If they're still tied, alphabetical order is fine.

It's only for me to use on my own computer, so I don't need accounts or anything online. I do want everything to still be there when I close or refresh the page. It should work well on my phone too, explain clearly when there's nothing to show or when something is locked, and show helpful messages when I enter something wrong.
